ES‑9

Capture

What the module sends to the computer and into the two mixers. Click a jack, then click one on the far row to patch.

Output

Where each USB playback channel and each mix is sent. Several may share a destination — the module sums them there.

Input DC blocking

The inputs are DC coupled, so they carry CV as happily as audio. Each ADC has a DC-blocking filter: turn it on for audio, and it must be off for CV — the filter removes exactly the constant offset a CV consists of.

The filters switch in pairs, and one pair is not what you would guess: inputs 3 and 8 share a filter. The pairing follows the ADC channels, not the numbers on the panel.

Output DC offsets

Trims a constant voltage on the eight 3.5mm analogue outputs. The module implements this with the mixer hardware, so an output with no mix routed to it ignores the setting entirely — those are marked below rather than left to fail silently. Double-click a slider to return it to zero.

To trim against a measurement rather than by ear, patch the output back into an input and watch the DC column on the Meters tab.

Input meters

The module reports no audio levels over MIDI, so these are measured from the sixteen USB capture channels. Each meter is labelled with whatever the routing currently sends to that channel — change the routing and the meters follow.

The DC column is the mean sample value. Peak and RMS both discard sign, so an idle channel resting at a constant voltage reads as silence on those two and only shows up here. Patch an output back to an input to trim its offset against this reading.

Factory defaults

Resets the current configuration to one of the module's two default sets. These are the module's own defaults, applied by the module — not this app's, and not your saved presets below. This does not touch either flash slot — the module keeps the change only until it is saved, so nothing is lost permanently until you press Save. Undo reverses it.

A factory reset also replaces your routing. If you have pointed USB capture channels at a mix to record a reference of what leaves the main outs, the factory config takes those channels back for the S/PDIF input.

Your presets

A preset is the module's own configuration dump, stored as a plain .syx file, so it is interchangeable with anything else that speaks the protocol. Loading one is a single undoable step and is verified by reading the configuration back.

Saving is tested; loading is not. No preset has yet been loaded onto a real module — the transport it uses is verified and the step is covered by tests against the mock, but the button itself is untried on hardware. It replaces the entire configuration, routing included. Save the current one first, so there is something to go back to.

Stereo links

A link merges two channels into one strip — and silently rewrites the CC map below. They sit together so a toggle and its consequence are visible at once.

Resolved MIDI CC map

CC numbers are fixed in hardware and cannot be reassigned. This is what they control under the current link configuration.

Protocol monitor

Every message in both directions. The byte after 34 is the CC number for the control you just moved.
